# CursorCat v4 🐈

Windows desktop pet built as one portable EXE.

## Что нового в v4
- Кот ходит **только по панели задач**, не по рабочему столу и не по окнам.
- `HWND_TOPMOST`: кот всегда поверх окон.
- Поддержка нескольких мониторов и переходов между их панелями задач.
- Прыжок между мониторами по дуге.
- Более объёмная, 3D-похожая отрисовка: мягкие градиенты, объём головы и тела, шерстяные блики, тени, глаза.
- Реакции: ходьба, пауза, пробуждение от курсора.
- Прозрачный фон и отсутствие отдельного консольного окна.
- Никакого Python на компьютере пользователя.

## Сборка
GitHub Actions автоматически собирает `CursorCat.exe` на Windows.
Откройте **Actions → Build CursorCat v4 → Run workflow**.
После успешной сборки скачайте artifact `CursorCat-v4-Windows`.

## Ограничение
В v4 реалистичность сделана нативным 3D-подобным рендером без внешних моделей и DLL, чтобы EXE оставался простым и надёжно собирался в GitHub Actions. Следующий этап может заменить процедурного кота на настоящую GLB-модель с PBR-материалами.
